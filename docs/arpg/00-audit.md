## What the brief asks for that does not exist yet

- Permanent species per character, several characters per family profile, character select (today: one record per profile, species swappable at the nest).
- Persistent character level / XP / skill points / skill tree / respec (today: XP-per-species drives 4 size stages only).
- Mutation equipment: slots, rarities, rolled stats, affixes, legendary effects, inventory, salvage (nothing).
- Quests and dialogue: only a linear `objective` string and mastery counters.
- Enemy variety: lungers + one sweeper boss. No ranged, ambusher, support, tank retaliation, multi-phase bosses.
- Numeric HP (today three hearts, fractional), damage numbers, enemy health bars, combos, perfect dodge.
- Death penalty (today none), checkpoints (today: nests), difficulty (today one assist toggle).
- World-state changes in response to bosses/quests; landmarks, hazards, secret encounters.

## Measured baseline

- `tsc --noEmit` clean; `vitest` 63/63 pass (2.4 s).
- Desktop headless Chrome, 1366×1024, Fern Hollow opening: **median 16.7 ms, p95 17 ms, max 33 ms** per rAF frame
  (60 Hz-locked), 276 live props, 42 fx, 4 ground tiles, 49 actors (12 views). This is **not** an iPad result.
- Payload: `public/art` 14 MB (creatures 13 MB, props 1.1 MB), `public/world` 7.9 MB (322 tiles), `dist` 25 MB; the PWA
  precaches only the opening area, art and world stream with runtime CacheFirst.
- Physical iPad memory/FPS: **not measured** in this environment. Marked open throughout; see `docs/arpg/progress.md`.

## Constraints carried forward

- No Game Kit imports. Phaser 4.2.1, TypeScript, Vite, PWA, local-first, iPad-first touch.
- Never write test data to the real family Firebase: all automated browsers block Firebase and use throwaway storage.
- Existing keys (`trex_progress_*`, `trex_adventure_v1_*`, `trex_profiles`, collection `tinyrex`) are never reset, renamed or
  deleted by the new code. New data lives under new keys.
- Art budget: reuse the existing Blender recipe and creature atlases; evolve through tint, scale, overlays and VFX.
